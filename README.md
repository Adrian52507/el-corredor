# El Corredor — Interactive Portfolio

An interactive pixel-art portfolio inspired by Lima's public bus system.
Navigate between sections by riding a stylized version of the bus "Corredor 201"
through a dynamic day/night city.

**Status:** 🚧 In active development

## Stack
- React + TypeScript
- PixiJS - 2D scene rendering
- GSAP - animation
- Tailwind CSS - UI styling
- Vite - build tooling

## Concept
A pixel-art avatar travels by bus between portfolio sections ("stops"),
each with its own themed background. Content for each section is shown
in a diegetic phone-screen popup, keeping the world always visible.

## Running locally
\`\`\`
npm install
npm run dev
